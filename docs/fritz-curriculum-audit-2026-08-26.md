## Recommended 20-25 minute lesson rhythm

- 1-2 min: Fritz greeting / student response
- 2-3 min: song or reusable micro-video
- 3 min: new letters and phonics
- 2-3 min: tap/listen/choose activity
- 3-4 min: illustrated story
- 2 min: comprehension mini-game
- 2-3 min: reader
- 2 min: movement/listening or builder-language task
- 2-3 min: cumulative review
- 1-2 min: reward reveal and builder placement

The pacing should visibly change activity every few minutes so the lesson feels like play rather than a long class period.

## Reusable media targets

- Alphabet song / alphabet movement clip
- Count 1-10 clip
- Core colors clip
- Shapes clip
- Hello / My name is / How are you? conversation clip
- Classroom action clip: open, close, give, show
- Position words clip: in, on, under, beside, behind, between
- Movement break clip using stand, sit, turn, clap, point
- W/X phonics micro-clip
- Y/Z phonics micro-clip
- Alphabet celebration/review clip

These should be designed for reuse across multiple lessons rather than assigned one-to-one to individual lessons.
